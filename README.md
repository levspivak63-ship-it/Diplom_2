Проект автоматизации тестов эндпоинтов API для Stellar Burgers.
Описание:
Проект содержит набор автотестов для проверки API учебного сервиса Stellar Burgers. Тесты покрывают основные эндпоинты: создание пользователя, авторизацию и создание заказов.
Технологии:
- Python 3.13
- pytest 8.4.2
- requests 2.31.0
- allure-pytest 2.15.0

Структура проекта:
stellarburgers_api_tests/
├── conftest.py           # Фикстуры pytest
├── data.py               # Константы и тестовые данные
├── helper.py             # Вспомогательные функции
├── requirements.txt      # Зависимости проекта
├── README.md             # Документация
└── tests/
    ├── test_create_user.py     # Тесты создания пользователя
    ├── test_login_user.py      # Тесты авторизации
    └── test_create_order.py    # Тесты создания заказа

Allure отчет
Проект интегрирован с Allure для формирования детальных отчетов.
